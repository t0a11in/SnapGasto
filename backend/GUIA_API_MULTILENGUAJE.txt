SNAPGASTO - GUIA RAPIDA DE API MULTILENGUAJE
==============================================

BASE COMPARTIDA
--------------
Motor: SQL Server
Servidor: localhost:1434 cuando SQL Server se inicia con Docker Compose (1433 dentro del contenedor)
Base: snap_gastos
Esquema: dbo
Tablas compartidas: users, categories, expenses, incomes, notifications

El esquema lo crea y evoluciona UNICAMENTE Spring Boot con Flyway.
No ejecutar migrate/makemigrations (Django), EnsureCreated/migrations (.NET)
ni DDL en Node. Django usa la tabla dbo.users existente y no usa auth_user.

CONTRATO QUE DEBE SER IGUAL EN TODAS
------------------------------------
JWT: HS256, mismo JWT_SECRET, sub=email normalizado, iat, exp.
Password: BCrypt costo 10 y formato $2a$.
Errores: {"message":"..."}.
JSON: camelCase.
Mantener el mismo DB_HOST/DB_PORT/DB_NAME/DB_USER/DB_PASSWORD y JWT_SECRET.

PUERTOS Y ARRANQUE
------------------
Spring Boot (original): 8080
  cd backend/snapgasto-backend
  docker compose up --build

.NET: 8081
  cd backend/snapGastosNet
  $env:ConnectionStrings__SnapGasto="Server=localhost,1433;Database=snap_gastos;User Id=sa;Password=CLAVE;Encrypt=True;TrustServerCertificate=True"
  $env:Jwt__Secret="MISMO_SECRETO_DE_32_O_MAS_CARACTERES"
  dotnet run --urls http://localhost:8081

Django: 8082
  cd backend/snapGastosDjango
  py -m venv .venv
  .\.venv\Scripts\python.exe -m pip install -r requirements.txt
  $env:DB_PASSWORD="CLAVE"
  $env:JWT_SECRET="MISMO_SECRETO_DE_32_O_MAS_CARACTERES"
  .\.venv\Scripts\python.exe manage.py runserver 8082

Node/Express: 8083
  cd backend/snapGastosNode
  npm install
  $env:DB_PASSWORD="CLAVE"
  $env:JWT_SECRET="MISMO_SECRETO_DE_32_O_MAS_CARACTERES"
  npm start

Para cambiar de una API a otra, deten la actual y levanta la siguiente
con el mismo SQL Server y el mismo JWT_SECRET. No hay exportaciones de
tablas ni se sobreescriben datos: todas trabajan directamente sobre dbo.

F5 EN VISUAL STUDIO CODE
------------------------
Antes de depurar por primera vez, crea los .env locales (no se versionan):
  Copy-Item backend\snapGastosNet\.env.example backend\snapGastosNet\.env
  Copy-Item backend\snapGastosDjango\.env.example backend\snapGastosDjango\.env
  Copy-Item backend\snapGastosNode\.env.example backend\snapGastosNode\.env
Completa las tres conexiones con la misma clave SQL Server y el mismo JWT_SECRET.

En Run and Debug selecciona una configuración y presiona F5:
  API · Spring Boot (Java)      -> 8080
  API · .NET (puerto 8081)      -> 8081
  API · Django (puerto 8082)    -> 8082
  API · Node/Express (puerto 8083) -> 8083

La configuración .NET compila antes de iniciar. Django requiere que exista
su .venv y Node requiere npm install, como se describe arriba.
